# Écho (Echo)

A memory game: four crystals light up in a precise order, each with its own note. Play the sequence back without a mistake; each round, it grows by one crystal.

*Version française : [README.md](README.md)*

## How to play

1. Watch and listen: the crystals light up one by one, each with its own note.
2. When the green dot lights up in the centre, it is your turn: play the sequence back in the same order.
3. If it is all right, a new crystal is added to the end of the sequence, and it plays a little faster.

A single mistake ends the game: the crystal you should have touched lights up to show you. **New game** starts again.

## Controls

- **Click** a crystal.
- On the keyboard: **1 2 3 4**, or the **arrows** (↑ top, → right, ↓ bottom, ← left).

## Speed

**Calm**, **Normal** or **Fast**: the starting speed of the sequences. Either way, they speed up a little each round.

Tip: each crystal has its own note, so listening helps as much as watching.

## Statistics

The Records panel shows your **longest sequence** completed and the number of **games**.

## Data and sync

Your record, number of games and chosen speed are stored by NeoDex, backed up and synced between your PCs when sync is on.

## Install

In NeoDex: **NeoStore → Discover → Écho → Install**.

Building a plugin: see the [NeoDex SDK](https://github.com/NDesumeur/neodex-sdk).
