# Écho

Quatre cristaux s'allument dans un ordre de plus en plus long. Rejoue la suite sans te tromper.

Les cristaux s'allument un par un. Quand le point vert s'allume au centre, rejoue la suite dans le même ordre. Une erreur termine la partie.

Ses données (records, réglages) sont rangées dans le dossier du plugin, que NeoDex sauvegarde (synchro cloud comprise).

## Installer

Dans NeoDex : **NeoStore → À découvrir → Écho → Installer**.

Développer un plugin : voir le [SDK NeoDex](https://github.com/NDesumeur/neodex-sdk).
